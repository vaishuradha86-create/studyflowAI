# StudyFlow – AI-Based Smart Study Assistant

A responsive college-project prototype for managing subjects, tasks, study plans, focus sessions, progress and study motivation.

## Features
- Dashboard with study statistics
- Subject and exam tracking
- Task manager with priorities and completion
- Smart study-plan generator
- Pomodoro focus timer
- Progress tracking
- XP, streaks and badges
- Light/dark mode
- LocalStorage persistence
- Responsive mobile layout

## Run
No backend is required for this prototype.

1. Download/extract the project.
2. Open `index.html` in a modern browser.
3. All demo data is stored locally in the browser.

## Future AI Integration
The current planner uses JavaScript logic. A future version can connect a secure backend to the Gemini API to provide personalized study plans, explanations, question generation, adaptive revision and progress recommendations.
